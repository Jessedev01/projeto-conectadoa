# ConectaDoa - Sistema de Gestão de Doações

## Sobre a ONG
A ConectaDoa é uma organização localizada em São Paulo, SP, cuja missão é conectar doadores a comunidades em situação de vulnerabilidade, intermediando a coleta e distribuição de alimentos, roupas e itens de higiene. Atende cerca de 500 beneficiários por mês com o apoio de 10 voluntários ativos.

## Descrição do Projeto
O ConectaDoa é um sistema web centralizado desenvolvido para substituir o uso de planilhas manuais na gestão de doações. Ele permite o cadastro de doadores, registro de doações em tempo real, geração de relatórios automáticos e consultas instantâneas, garantindo a integridade dos dados e otimizando o tempo dos voluntários.

## Estrutura do Repositório
- `/docs`: Contém o Documento de Visão e relatórios do projeto.
- `/backend`: API REST (Node.js + Express). *(A ser implementado no PIE II)*
- `/frontend`: Aplicação Web (React). *(A ser implementado no PIE II)*
